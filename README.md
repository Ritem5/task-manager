# Консольный менеджер задач

Консольная программа на Java для ведения списка задач: можно добавлять задачи,
отмечать выполненные, удалять их. Список сохраняется в файл и не пропадает
после перезапуска.

## Возможности

- Добавление, просмотр, отметка о выполнении и удаление задач
- Сохранение задач в файл `tasks.txt` и загрузка при запуске
- Обработка ошибок ввода: неизвестная команда, команда без аргумента,
  номер не числом, несуществующий номер

## Запуск

Нужна Java 21 или новее.

1. Склонируйте репозиторий и откройте проект в IntelliJ IDEA.
2. Запустите класс `TaskManager`.
3. Введите `help`, чтобы увидеть список команд.

Задачи сохраняются в `tasks.txt` в папке проекта при выходе командой `exit`.

## Команды

| Команда | Что делает |
| --- | --- |
| `help` | Показать список команд |
| `add <текст>` | Добавить задачу |
| `list` | Показать все задачи с номерами |
| `done <номер>` | Отметить задачу выполненной |
| `delete <номер>` | Удалить задачу |
| `exit` | Сохранить задачи и выйти |

## Пример работы

```
> add Купить хлеб
Добавлено: Купить хлеб
> add Приготовить ужин
Добавлено: Приготовить ужин
> done 1
Готово
> list
1. [x] Купить хлеб
2. [ ] Приготовить ужин
> delete 1
Удалено
> exit
```
